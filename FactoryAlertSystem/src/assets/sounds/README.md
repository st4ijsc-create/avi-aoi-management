# Assets Placeholder

Vui lòng thêm các file sau vào thư mục này:

1. `icon.png` - Icon ứng dụng (1024x1024 px)
2. `splash.png` - Splash screen (1284x2778 px)
3. `adaptive-icon.png` - Android adaptive icon (1024x1024 px)
4. `alert.wav` - File âm thanh cảnh báo

## Tạo icon nhanh

Bạn có thể sử dụng các công cụ online:
- https://makeappicon.com/
- https://appicon.co/

## File âm thanh

Có thể tải file âm thanh miễn phí từ:
- https://freesound.org/
- https://mixkit.co/free-sound-effects/

Định dạng: WAV hoặc MP3
Thời lượng khuyến nghị: 1-3 giây
