Viết TypeScript dùng drizzle-orm 0.44 (PostgreSQL, driver postgres.js). Bảng đã có: dem_loi(ma text primary key, so_lan integer not null default 0, cap_nhat timestamp with time zone not null default now()). (1) export const demLoi — khai báo bằng pgTable ("drizzle-orm/pg-core") với thuộc tính ma, soLan, capNhat. (2) export async function congDon(db: PostgresJsDatabase, ma: string, them: number): Promise<{ ma: string; soLan: number; moi: boolean }> (PostgresJsDatabase từ "drizzle-orm/postgres-js") — them phải là số nguyên > 0, sai ⇒ ném RangeError mà không chạm db. Dùng MỘT câu INSERT … ON CONFLICT (ma) DO UPDATE của drizzle (onConflictDoUpdate) để cộng dồn NGUYÊN TỬ: chưa có ⇒ so_lan = them; đã có ⇒ so_lan = so_lan cũ + them và cap_nhat = now(); trả về qua returning: ma, soLan sau cập nhật, moi = true nếu dòng vừa được THÊM MỚI, false nếu là cập nhật (gợi ý PostgreSQL: biểu thức (xmax = 0) trong RETURNING). Phải đúng khi nhiều lời gọi chạy ĐỒNG THỜI trên cùng ma. Chỉ trả về MỘT khối mã TypeScript.
