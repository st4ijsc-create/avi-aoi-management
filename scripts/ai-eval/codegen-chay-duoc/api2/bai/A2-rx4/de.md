Viết React 19.2 + TypeScript (một tệp TSX, nhập từ "react"): export function PhongTheoDoi(props: { phong: string; donVi: "C" | "F"; nguong: number; baoDong: (thongDiep: string) => void; ketNoi: (phong: string, khiCoGiaTri: (doC: number) => void) => () => void }) — hiển thị <p>Phòng {phong}</p>. Một effect gọi ketNoi(phong, cb) và dùng hàm mà ketNoi trả về để ngắt khi dọn. CHỈ kết nối lại khi phong đổi — đổi donVi, nguong, baoDong (kể cả hàm mới mỗi lần render) hay ketNoi đều KHÔNG được kết nối lại. Khi cb nhận giá trị doC (độ C): nếu doC > nguong (nguong tính bằng độ C) thì gọi baoDong(phong + ": " + chuoi) với chuoi = donVi "C" ⇒ doC.toFixed(1) + "°C"; donVi "F" ⇒ (doC * 9 / 5 + 32).toFixed(1) + "°F" — luôn dùng donVi, nguong, baoDong MỚI NHẤT tại lúc nhận giá trị.
