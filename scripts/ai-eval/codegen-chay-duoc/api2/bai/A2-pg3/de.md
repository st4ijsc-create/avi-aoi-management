Viết mã PostgreSQL tạo hàm: CREATE OR REPLACE FUNCTION ghi_dem(p_ma text, p_them integer) RETURNS TABLE(ma text, so_lan integer, moi boolean). Bảng đã có: dem_loi(ma text primary key, so_lan integer not null). Hàm cộng dồn NGUYÊN TỬ bằng MỘT câu INSERT … ON CONFLICT (ma) DO UPDATE: chưa có ⇒ thêm với so_lan = p_them; đã có ⇒ so_lan = so_lan cũ + p_them; trả ĐÚNG MỘT hàng: ma, so_lan sau cập nhật, moi = true nếu dòng vừa được THÊM MỚI (gợi ý: xmax = 0 trong RETURNING). p_them NULL hoặc <= 0 ⇒ RAISE EXCEPTION với SQLSTATE '22023' (invalid_parameter_value) và không ghi gì. Phải đúng khi nhiều phiên gọi ĐỒNG THỜI cùng p_ma. Lưu ý tên cột đầu ra của RETURNS TABLE trùng tên cột bảng. Chỉ trả về MỘT khối mã SQL.
