# Mapping-as-code — `contracts/mappings/`

doc 44 Batch W2-B3 (gap G1.13) — SYNAPSE Tầng-1 Chương 10: *"Ánh xạ là 'hợp đồng
khai báo' (as-code) gắn địa chỉ thô của hãng với tag/đơn vị/scale canonical —
nơi tri thức tích hợp được ghi lại tường minh, versioned trong Git."*

Mỗi file `{adapter-code}.mapping.yaml` là bản khai báo **đầy đủ, mong muốn**
(desired state) của mapping một adapter:

- `tags:` — các điểm đọc (`device_tags`): address / datatype / unit / scale /
  offset / writable / enabled / deadband / sampling_ms.
- `uns_mappings:` — conditioning publish lên UNS (`uns_tag_mappings`):
  uns_topic / sparkplug_metric / transform (rename·scale·offset·unit·cast·deadband).
- Khóa tự nhiên = **adapter code + tag name** (không dùng id số) ⇒ file portable
  giữa dev/staging/prod.
- File **không** chứa endpoint/credentials — import không tạo/sửa adapter,
  không đổi `machineId`. `machine`/`vendor` chỉ để người review đối chiếu
  (lệch ⇒ warning, không chặn).

## Định dạng

```yaml
# generated by mappings-export — REVIEW trước khi import
version: 1                 # BẮT BUỘC bump khi đổi nội dung (số nguyên, tăng dần)
adapter: plc-line1         # device_adapters.code (khóa tự nhiên)
machine: M-AOI-01          # machines.code | null (thông tin — import không đổi)
vendor: modbus             # protocol của adapter (thông tin)
tags:
  - name: torque
    address: "40001"
    datatype: float        # bool | int | float | string | json
    unit: "N·m"
    scale: 1
    offset: 0
    writable: false
    enabled: true
    deadband: 0.05         # tùy chọn (report-by-exception, G1.4)
    sampling_ms: 1000      # tùy chọn
uns_mappings:
  - tag: torque
    uns_topic: "syn/{enterprise}/{adapterCode}/{rename}"
    sparkplug_metric: screw.torque
    enabled: true
    transform: { rename: screw.torque, scale: 0.1, unit: "N·m", cast: number, deadband: 0.05 }
```

Export luôn **ổn định thứ tự key + sort tag theo name** ⇒ cùng dữ liệu cho cùng
bytes, diff Git sạch. Field null bị lược bỏ.

## Quy ước review (BẮT BUỘC)

1. **Mọi thay đổi mapping đi qua PR** — không sửa tay DB rồi bỏ quên file, không
   import file chưa được duyệt. File trong Git là nguồn sự thật tri thức tích hợp.
2. **Bump `version`** ở mỗi thay đổi nội dung. Import từ chối file có
   `version` **nhỏ hơn** version đã import (chặn file cũ đè bản mới); version
   bằng nhau được phép (re-apply idempotent).
3. **Prune cần approve tường minh**: mặc định import KHÔNG xoá tag/mapping có
   trong DB nhưng vắng mặt trong file (chỉ liệt kê trong diff). Chỉ chạy
   `--prune` / `prune: true` khi PR ghi rõ ý định xoá và đã được duyệt.
4. Reviewer soi kỹ: đổi `address`/`datatype`/`scale` (sai đơn vị = dữ liệu sai
   hàng loạt), bật `writable` (khai báo tag có thể là target ghi — write thật
   vẫn qua commandDispatcher đầy đủ gate), đổi `uns_topic` (đổi hợp đồng dữ liệu
   cho tầng trên).

## Quy trình chuẩn (export → commit → review → import)

```
# 1. Ở env nguồn (hoặc sau khi chỉnh qua UI): export ra Git
node scripts/mappings-export.mjs                       # tất cả adapter
node scripts/mappings-export.mjs --adapter plc-line1   # một adapter

# 2. Commit + mở PR — review theo quy ước trên, bump version.

# 3. Ở env đích: dry-run xem diff (mặc định KHÔNG ghi)
node scripts/mappings-import.mjs contracts/mappings/plc-line1.mapping.yaml

# 4. Duyệt xong → apply (thêm --prune CHỈ khi PR duyệt việc xoá)
node scripts/mappings-import.mjs contracts/mappings/plc-line1.mapping.yaml --apply
```

Tương đương trong app (tRPC, RBAC `machine_control`): `mappingAsCode.list` /
`.exportOne` / `.exportAll` (admin) / `.preview` (dry-run) / `.apply`
(**admin + 2FA**, audit tự động).

## Sau khi apply

- Import chạy trong **một transaction**; version + hash được lưu vào
  `config_snapshots` (`entity_type='mapping_file'`, `entity_id=adapter id`).
- Apply qua app còn: ghi audit `mapping_as_code.import`, clear UNS mapping
  cache, và **refresh baseline config-drift** (import = bản approved mới, G1.11).
- Import **không restart adapter**. Nếu kết quả trả `requiresAdapterRestart:
  true` (device_tags đổi) — người vận hành chủ động restart adapter/app; thay
  đổi chỉ ở `uns_mappings` có hiệu lực ngay (qua app) hoặc sau restart (qua CLI).
