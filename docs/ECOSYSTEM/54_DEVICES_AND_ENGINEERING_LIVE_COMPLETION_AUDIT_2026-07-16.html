3 · Module "Thiết bị & Giám sát"

3.1 P0/P1 Bảo mật & RBAC (backend — đã tự kiểm chứng)

  • P0-1 Rò apiKey máy plaintext cho MỌI user (kể cả viewer). machine.getById bare procedure trả SELECT * gồm apiKey (hierarchy.ts:444). Mở lại lớp lỗ hổng doc-51.
  • P0-2 Phi-admin đặt apiKey tuỳ ý + tự duyệt đăng ký. machine.update nhận apiKey+registrationStatus dưới settings_factory/canEdit (mở cho engineer). Audit che value → vô hình.
  • P1-3 OEE/downtime/health viewer ghi được, một cái tới ERP outbox (mqttOeeRouters.ts:422…).
  • P1-4 Ngưỡng chất lượng toàn nhà máy + ack chéo-user ai cũng ghi (alertRouters.ts:394,347). UI gate nhưng server không.
  • P1-5 Publish MQTT + config + analytics ai đăng nhập cũng chạy (nhiều bare procedure) → đầu độc dữ liệu.
  • RBAC Đọc inventory fleet không gate; broker auth auto-accept PENDING; robot-control "403 lệch" (engineer thấy nút Điều khiển/Test → bấm 403, kiểm chứng live).

3.2 Data-integrity

  • N+1 @60s getAllMachinesWithStatus = 1+3N không cap; OEE-health + MQTT-replay in-memory (rỗng sau restart); analytics reconnect success==fail==total + heatmap bỏ Chủ nhật; thiếu UNIQUE oee_metrics; secret at-rest plaintext.

6 · Cross-cutting

  • i18n: raw key ở Login ("Login subtitle/Username placeholder"), Account ("Title"), OEE ("Subtitle"); hardcode VN ở FactoryCommand/CMMS/ECN/War-room/Feeder/Changeover; mixed EN/VN trong 1 hàng.
  • RBAC pattern hệ thống: "chỉ bit per-user, không sàn role" + route-guard chỉ ở client → biên thật là procedure server, mà nhiều mutation là bare protectedProcedure.
  • 2FA không đồng nhất: engineer1 bị hỏi OTP, operator1 không (dù seed đặt bật cả hai).
  • Thiết kế/màu: nhất quán dark+teal, spacing tốt, empty/denied-state đẹp — ~8/10. Trừ: lưới 2D quá tối giản; dock overlay che editor; vài nhãn lowercase.

7 · Kế hoạch nâng cấp & hoàn thiện (đề xuất — chờ duyệt)

Sắp theo rủi ro giảm dần. Mỗi đợt = một lô agent chuyên môn, green-gate (NODE_OPTIONS=--max-old-space-size=8192 tsc + build) sau mỗi đợt.

Đợt A — P0 bảo mật credential (chặn ship)
  • Strip apiKey khỏi getById/getStats/mọi full-row (P0-1).
  • Gỡ apiKey+registrationStatus khỏi machine.update, chuyển admin-only + step-up (P0-2).
  • Hash machines.apiKey + broker password at-rest.
Đợt B — an ninh hoá RBAC đồng bộ
  • writeProcedure/sàn role dưới MỌI mutation: OEE/downtime/health, yieldThreshold+alert, MQTT publish/config, device-config.
  • Interlock → actuationProcedure; approve → adminProcedure.
  • Gate đọc inventory fleet; sửa "403 lệch" robot (ẩn nút); ECN gate lại theo engineering; SoD governance.
Đợt C — data-integrity & correctness
  • Fix OEE dashboard đọc rỗng (P1 FE — ưu tiên: user thấy ngay).
  • UNIQUE chống trùng OEE/health; WORM thực thi (REVOKE/trigger); robot_telemetry retention 365d.
  • Version-race → txn+retry; fix analytics reconnect/heatmap; persist OEE-health + replay; N+1 fleet set-based.
Đợt D — lấp dữ liệu (hết rỗng)
  • Seed Engineering (projects/builds/deploy/sim, recipes, interlock events, ECN, equipment) + automation-demo (fleet) + MQTT/edge/uns + heartbeats + changeover.
Đợt E — i18n & FE polish
  • Điền raw key Login/Account/OEE; i18n-hoá các trang hardcode VN; dứt mixed EN/VN.
  • Nâng lưới 2D factory-command (nhãn/nhóm Line/mini-KPI); dock overlay→push/resizable; gỡ trùng Work Orders; chuẩn 2FA.
Đợt F — (không code) chủ nhà máy/HW
  • Bật cờ an toàn đúng thứ tự TRƯỚC DPC_DEPLOY_ENABLED; default-deny broker; dọn .env.
